# KINGS AXIS ERP — demo site (www.kingsaxis.com)

- `index.html` — the complete ERP demo (single file, works offline).
- `CNAME` — tells GitHub Pages to serve this at www.kingsaxis.com. Do not delete.
- Access code for the demo gate: **KINGS2026** (change `DEMO_CODE` inside index.html).
  The gate is demo-grade only — the code is visible in the page source. Real user
  logins arrive with the production build.

To update the site later: replace `index.html` with the newer file and commit — the
site refreshes in ~1 minute.
